# قسط‌یار

وب‌اپ ساده برای ثبت وام‌ها و مشاهده اینکه هر ماه چقدر قسط باید بدهی، به همراه چشم‌انداز ماه‌های آینده.

## اجرا

```bash
npm install
cp .env.example .env
npx prisma migrate deploy
npm run dev
```

سپس http://localhost:3000 را باز کنید.

## امکانات

- ثبت/ویرایش/حذف وام با مبلغ کل، مبلغ هر قسط، تعداد اقساط و تاریخ شروع
- جدول ماهانه با جمع کل اقساط هر ماه و جزئیات هر وام در آن ماه
- نمودار روند اقساط برای ۶، ۱۲ یا ۲۴ ماه آینده
- جمع اقساط ماه جاری

## استک فنی
